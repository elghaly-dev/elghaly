# Contributing

Thanks for your interest in improving this project. Contributions of all sizes are welcome.

## Opening an issue

- Search [existing issues](../../issues) first to avoid duplicates.
- Describe what you expected, what happened, and how to reproduce it (page URL, browser, steps).
- Do not include passwords, keys, or other private information in an issue.

## Opening a pull request

1. Fork the repository and create a branch from `main`.
2. Keep the change small and focused; one topic per pull request.
3. Describe what changed and why in the pull request.
4. A maintainer will review it. Please be patient and open to feedback.
